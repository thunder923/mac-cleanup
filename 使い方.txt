Macお片付け v1.0
================

Macの容量整理ツールです。このMacの中の大容量ファイルを自動で探して、
「安全に消せる / 重複 / 要判断」に分けて表示します。

使い方
------
1. 「Macお片付け.app」をアプリケーションフォルダ（または好きな場所）へ置く
2. ダブルクリックで起動 → ブラウザに整理画面が開く
   ※ 初回だけ「開発元が未確認」と出たら、右クリック →「開く」で起動してください
3. スキャンが終わるのを待つ（フォルダ集計は少し時間がかかります）
4. 消したいファイルにチェック → 下の「ゴミ箱へ入れる」
   → 確認画面で対象を確認して実行。Finderのゴミ箱へ入るので、あとから戻せます

機能
----
- ディスク使用量（合計 / 使用中 / 空き）を表示
- フォルダ別ランキング：ホーム直下の各フォルダ＋ Library の重い場所を再帰集計
- 大容量ファイルを分類
  - 安全：インストーラー（DMG/PKG）、未完了ダウンロード（.part など）
  - 重複：同サイズ＋内容ハッシュが一致するファイル（残す方も表示）
  - 要判断：それ以外の大容量ファイル（サイズ順）
- Finderで表示ボタン、最小サイズの切り替え（10MB〜1GB）、再スキャン

安全対策
--------
- 削除は「ゴミ箱へ移動」だけ。完全削除はしません
- ホームフォルダ配下以外のファイルは対象にできません
- 通信はこのMacの中（127.0.0.1）だけ。外部にデータは送りません

動作条件
--------
- macOS 11 以降 / python3（Xcode Command Line Tools）
  無い場合は起動時に案内が出ます。そのときはターミナルで
  xcode-select --install を実行してください

終了方法
--------
ブラウザのタブを閉じても裏で動いたままになります。
止めたいときはアクティビティモニタで python3 を終了するか、
ターミナルで次を実行してください:
  pkill -f "Macお片付け.app/Contents/Resources/server.py"

ログ: ~/Library/Logs/MacCleanup.log
