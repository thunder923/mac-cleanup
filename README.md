# Macお片付け

Mac の容量整理ツール。ホームフォルダの中の大容量ファイルを自動で探して、
「安全に消せる / 重複 / ライブラリ / 要判断」に分けて表示し、選んだものを Finder のゴミ箱へ入れる。
削除ではなくゴミ箱への移動だけなので、あとから戻せる。

同梱の `使い方.txt` が利用者向けの簡易マニュアル、この README は構成と仕組みの記録。

## 構成

| ファイル | 役割 |
|---|---|
| `Macお片付け.app/Contents/MacOS/MacCleanup` | ランチャー（shスクリプト）。同梱サーバーを起動してブラウザを開く |
| `Macお片付け.app/Contents/Resources/server.py` | 本体。Python 標準ライブラリのみのローカルサーバー（追加インストール不要） |
| `使い方.txt` | 利用者向けマニュアル |

## 起動方法

1. `Macお片付け.app` をアプリケーションフォルダ（または好きな場所）へ置く
2. ダブルクリックで起動 → ローカルサーバー（http://127.0.0.1:17890）が立ち、ブラウザに整理画面が開く
   - 初回だけ「開発元が未確認」と出たら、右クリック →「開く」で起動する
   - 既に起動中なら、サーバーは多重起動せずブラウザだけ開く
3. スキャンが終わるのを待つ（フォルダ集計は少し時間がかかる）
4. 消したいファイルにチェック → 下の「ゴミ箱へ入れる」→ 確認画面（モーダル）で対象を確認して実行

- 終了方法: ブラウザのタブを閉じても裏で動いたままになる。止めたいときはアクティビティモニタで python3 を終了するか、ターミナルで
  `pkill -f "Macお片付け.app/Contents/Resources/server.py"`
- ログ: `~/Library/Logs/MacCleanup.log`

## できること

- **ディスク使用量**（合計 / 使用中 / 空き）を表示
- **フォルダ別ランキング**: ホーム直下の各フォルダ＋ Library の重い場所を再帰集計
- **大容量ファイルの分類**（既定では 50MB 以上。画面で最小サイズを 10MB〜1GB に切り替え可）
  - **安全に消せるもの**: インストーラー（DMG/PKG、対応アプリがインストール済みかも判定）、未完了ダウンロード（`.part` `.crdownload` `.download` `.opdownload`）、ライブラリ内のキャッシュ系（Caches / Logs / HTTPStorages / Saved Application State）
  - **重複してるもの**: 同サイズ＋部分ハッシュ（先頭・中間・末尾）が一致するファイル。置き場所の優先度で「残す方」を決めて表示し、消す側だけが対象になる
  - **ライブラリの中身（要注意）**: 上記以外の Library 配下。アプリのデータ本体が多いので内容確認のうえで判断する分類
  - **大容量ファイル（要判断）**: それ以外をサイズ順に表示
- 「安全＋重複だけ全選択」ボタン、Finderで表示ボタン、再スキャン

## 安全対策（仕組み）

- 削除は **ゴミ箱へ移動のみ**。完全削除はしない（同名ファイルがゴミ箱にある場合は連番を付けて上書きしない）
- 対象は **ホームフォルダ配下だけ**。それ以外のパスはサーバー側で受け付けない
- **絶対に消しちゃダメな場所は最初から表示しない**: キーチェーン（パスワード）・メール・メッセージ・写真・カレンダー・連絡先・アカウント・Safari・設定ファイルなど
- 通信はこの Mac の中（127.0.0.1）だけ。外部にデータは送らない

## 動作条件

- macOS 11 以降 / python3（Xcode Command Line Tools）
  - python3 が無い場合は起動時にダイアログで案内が出る。そのときはターミナルで `xcode-select --install` を実行する
